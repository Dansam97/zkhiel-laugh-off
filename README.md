Entry for the make.fun bounty [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae): a tiny program that writes exactly one funny line to `entry.txt`. The line is judged head-to-head against other one-liners on how hard it lands, the surprise of its turn, its economy of words and its freshness.

The joke: a fitness tracker congratulates its owner on 10,000 steps — while the owner is eating chips in a vibrating massage chair.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set). The output is deterministic: repeated runs produce byte-identical files.
